# HWCS - Handwriting Classification System

AI-powered writer identification system that classifies handwriting samples from three writers (Hasnain, Mehdy, and Umair).

## Features

- **Advanced ML Model**: K-Nearest Neighbors with 27 features (GLCM, LBP, statistical)
- **Interactive Demo**: Pre-loaded samples and custom upload
- **Fast Predictions**: Real-time classification

## Try It

Upload a handwriting sample or try the demo images to see the AI classify the writer!

## Dataset

Training data available at: https://github.com/Hasnain-Fatmi/HWCS/tree/main/orignal_images
